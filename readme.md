Magnet Brain - Frontend

This is the frontend of the Magnet Brain project, built with Next.js.

🚀 Tech Stack • Next.js • React • Tailwind CSS (optional styling) • Axios (for API calls)

📂 Project Setup 1. Clone the repository: git clone https://github.com/Anirudh3434/magnet-brain-frontend.git

Navigate to the folder: cd magnet-brain-frontend

Install dependencies: npm install

Run the development server: npm run dev
